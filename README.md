# Trạm Cuối

Game sinh tồn 2D đầu tiên của tôi, được xây dựng bằng Unity và C#.

Người chơi bảo vệ nhà ga và sống sót qua 3 đợt quái.

## Điều khiển

- WASD hoặc phím mũi tên: di chuyển
- Chuột: ngắm
- Giữ chuột trái: bắn
- Esc: tạm dừng

## Tính năng

- Di chuyển và va chạm 2D
- Ngắm và bắn bằng chuột
- Quái đuổi theo người chơi
- Máu, sát thương và thời gian miễn sát thương
- 3 đợt quái, tính điểm, thắng/thua
- Menu, tạm dừng và chơi lại
- Âm thanh và hiệu ứng trúng đạn

## Chơi thử

Tải bản macOS hoặc Windows trong mục Releases.

## Chạy mã nguồn

1. Clone repository.
2. Thêm project vào Unity Hub.
3. Dùng phiên bản Unity ghi trong ProjectSettings/ProjectVersion.txt.
4. Mở scene MainGame và bấm Play.

## Tôi đã học được

- Vòng đời MonoBehaviour
- Rigidbody2D và Collider2D
- Prefab và Instantiate
- Coroutine
- Quản lý trạng thái game
- UI và âm thanh
- Build game cho desktop
